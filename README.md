# Cloudflare Pages Deploy Repo

This directory is intended to live in a separate Git repository that is connected to Cloudflare Pages.

It only contains public, static artifacts:

- `index.html`: landing page
- `reddit/`: public Reddit dashboard assets
- `youtube/`: public YouTube dashboard assets
- `last-updated.json`: metadata generated by the sync script

Recommended workflow:

1. Keep running the data pipelines in the main project repo.
2. Run `./sync_public_site.sh` from the main project repo.
3. Commit and push the contents of this directory to the separate deploy repo.
4. Let Cloudflare Pages redeploy automatically from that repo.
